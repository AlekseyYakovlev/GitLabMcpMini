## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent -> server stdin | JSON-RPC from the agent/LLM; tool arguments are untrusted |
| server -> stdout | protocol channel; any non-JSON-RPC byte breaks the session |
| env -> server | GITLAB_TOKEN and GITLAB_URL from the agent config |
| server -> GitLab (HTTPS) | token leaves the process only in the PRIVATE-TOKEN header |
