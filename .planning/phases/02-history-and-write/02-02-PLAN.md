## Phase Goal

**As a** автор агента AiAdventAgentV2, **I want to** через `gitlab-mcp.exe` просматривать ветки, историю коммитов и различия и вносить изменения в репозиторий (создать ветку, закоммитить один или несколько файлов), **so that** агент может не только читать код, но и готовить изменения для будущего Merge Request.

<objective>
Second vertical slice: the agent reads commit history (`list_commits`, READ-06, D-14) and opens one commit with its diff (`get_commit`, READ-07, D-10, D-11, D-13). The diff renderer built here is shared by `compare_refs` (Plan 03) and by the per-file stats of `commit_files` (Plan 04).

Recorded deviation from RESEARCH (follows locked D-11 instead): RESEARCH recommended inferring the empty-patch reason because client-go's `gitlab.Diff` lacks `collapsed`/`too_large`. D-11 requires the reason to be explicit and it is technically feasible, so this plan decodes the commit-diff response into its own `diffFile` struct (same fields + `collapsed`, `too_large`) using client-go's exported `NewRequest`/`Do` and `gitlab.PathEscape` — the exact escaping client-go uses internally (`ProjectID` and `withPath` call `PathEscape`), verified by a wire test that compares our RequestURI with the one produced by `Commits.GetCommitDiff`. Inference is kept only as the fallback when both flags are false.

Output: `commits.go`, `diff.go` + tests, 9-tool e2e/smoke.
</objective>
