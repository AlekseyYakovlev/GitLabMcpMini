## Phase Goal

**As a** автор агента AiAdventAgentV2, **I want to** через `gitlab-mcp.exe` просматривать ветки, историю коммитов и различия и вносить изменения в репозиторий (создать ветку, закоммитить один или несколько файлов), **so that** агент может не только читать код, но и готовить изменения для будущего Merge Request.

<objective>
Third vertical slice: the agent compares two branches or commits (`compare_refs`, UTIL-02, D-12) — the natural check "what will my branch bring into main" before a Merge Request (Phase 3).

Same D-11 approach as Plan 02: the compare response is decoded into an own struct so `collapsed`/`too_large` reach `renderDiffFiles` (client-go's `gitlab.Compare.Diffs` drops them); the request path uses `gitlab.PathEscape` and is pinned by a wire test against `Repositories.Compare`. No `straight` parameter (deferred idea).

Output: `compare.go` + tests, 10-tool e2e/smoke.
</objective>
