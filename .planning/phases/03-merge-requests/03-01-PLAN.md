## Phase Goal

**As a** автор агента AiAdventAgentV2, **I want to** через `gitlab-mcp.exe` вести Merge Request от просмотра до merge (список, детали, diff, комментарии, создание, правка, влитие), **so that** агент доводит свои изменения из Phase 2 до влитой ветки без ручной работы в GitLab.

<objective>
First vertical slice of Phase 3: the agent finds open MRs of a project (MR-01) and reads one MR in detail with an explained `detailed_merge_status` (MR-02). The shared status table built here (`mr_status.go`) is reused unchanged by the merge pre-check in Plan 05 (D-04, D-12).

Purpose: before touching an MR the agent must see which MRs exist and whether one can be merged, and why not.
Output: `mr.go` (list/get), `mr_status.go`, tests, 14-tool golden/e2e/smoke.
