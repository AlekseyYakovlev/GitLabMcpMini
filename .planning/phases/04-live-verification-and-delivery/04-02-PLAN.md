CLI contract of scripts/live.py (README in Plan 03 documents exactly this):
- `uv run scripts/live.py --project GROUP/PROJECT [--exe PATH] [--out PATH]`
- `--project` required, no default (argparse required=True -> exit 2 when missing).

- Env: `GITLAB_TOKEN` (scope api) required; `GITLAB_TOKEN_READONLY` (scope read_api) optional. `GITLAB_URL` is never read or passed (gitlab.com only).
- Exit codes: 0 = every step PASS (the read-only block may be SKIPPED only when GITLAB_TOKEN_READONLY is unset), 1 = any FAIL or cleanup incomplete, 2 = usage/env error (missing token, missing exe) — exit-2 paths write NO transcript and touch no network.

Server output formats to parse (verified in code, RESEARCH Code Example 2):
- whoami (internal/tools/whoami.go): first line `@<username> (<name>), id <N>, state <s>, <web_url>`, second line `token: scopes [a, b], expires ...` or `token: scopes unavailable`
- get_project: line `default_branch: <name>`
- create_branch: `ветка <name> создана от ...`
- commit_files: first line `коммит <short8> в <branch> (+a/−r): K файла`, then `create <path> (+a/−r)` lines
- create_or_update_file: starts `created <path>: коммит ...` or `updated <path>: коммит ...`
- create_merge_request: `MR !N создан: src→dst`; duplicate: starts `открытый MR уже есть: !N`
- create_merge_request_note: `комментарий #ID добавлен к MR !N`
- get_merge_request: line `detailed_merge_status: <status> — <advice>` (regex `detailed_merge_status: (\w+)`)
- merge_merge_request: `MR !N влит (state=merged)` plus one of `merge commit:`, `squash commit:`, `head sha (fast-forward):`
- errors (internal/tools/errors.go, mr_status.go): 401 starts `401: GitLab отклонил токен`; write 403 starts `403: запись отклонена:` and contains "scope `api`"; 404 starts `404: не найдено`; duplicate branch contains `ветка уже существует`; draft refusal contains `draft_status`/`Draft`; merged MR refusal contains `not_open` or `MR не открыт`; 999.1 contains `непустой content`

mcp 1.30.0 stdio_client does NOT inherit GITLAB_TOKEN from the parent env: every session passes env explicitly.

Write tools (guarded set, used by Task 1's guard and Tasks 2-3): create_branch, commit_files, create_or_update_file, create_merge_request, update_merge_request, merge_merge_request, create_merge_request_note.
